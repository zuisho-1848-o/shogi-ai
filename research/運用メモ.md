## 2. 裏で計算を回すときの注意（やってみて分かったこと）
### CPU（発熱・ファン）
- **重い処理は同時に1つまで**。`taskpolicy -b`（省電力コア）で動かす
- `nice -n 19` は優先度を下げるだけで、使うコアの数は減らない。高性能コアを複数全開にするとファンが回る（2026-10-21、3つ並行で指摘された）
- sklearn の決定木などは OpenMP で全コアを使う → `OMP_NUM_THREADS=1〜2` に固定する（1局面ずつ評価する用途では1スレッドの方が約10倍速かった）
- 複数の実験は順番待ちで1つずつ回す（一時停止 `kill -STOP` → 前のが終わったら `taskpolicy -b -p <pid>` して `kill -CONT`）

### メモリ
- **メモリを大きく使う処理に `taskpolicy -b` を使わない**。macOS がメモリを圧縮・退避させて、処理がほぼ止まる（どうぶつしょうぎの解析で 1.9GB 中 1.5GB が圧縮され CPU 0% になった）
- 大きい配列は**ファイルに mmap** する。OS がいつでもページを捨てられるので、スワップを増やさない（このMacは仮想マシンなどで元からスワップが 17GB ほど使われている）
- `lab/tools/guard.sh` を常駐させる: 空きメモリが 15% を切ったら実験プロセスを一時停止、25% を超えたら再開。新しい実験スクリプトを足したら `PATTERN` に名前を加えて再起動する（ユーザーが使うやねうら王は対象外）

### 順番待ち・待ち合わせのスクリプト
- **`pgrep -f 名前` は、その名前を含む他のシェル（待ちスクリプト自身など）も拾う**。2つの待ちスクリプトが互いを「まだ動いている」と誤認して止まった（2026-10-21）→ `pgrep -f '^[^ ]*python[0-9.]* x13_mix.py'` のように、実行中の python の行だけに絞る
- 待ちスクリプトを新しく置くときは、古い待ちスクリプトが残っていないか確かめて、要らなければ止める

### その他
- **PC や Claude Code が再起動すると、裏の処理・順番待ち・guard.sh は全部止まる**（2026-10-21 に一度起きた）。再起動後は、`ps` で何が残っているか、各ログがどこまで進んだかを確かめ、guard.sh を起動し直してから、途中の実験を1つずつ再開する
- 長い処理は中断しても続きから再開できるように作る（例: `lab/corpus/analyze_positions.py` は出力済みの局面を飛ばす。`--shard/--nshards` で分割並列）
- 子プロセスを毎回起動すると、起動時の準備（索引の構築など）が毎回走って極端に遅くなる → 起動したままにして対話的にやりとりする（`sample expand` モード）

## 3. 環境まわり
- 実験用の Python は `lab/.venv`（Python 3.12）。kifu_review の `.venv`（3.14）とは分けている
- **cshogi はそのままではビルドできない**（新しい clang で `src/square.hpp` の enum の定数式がエラー）。ソースを取得して `SQWW_R = int(DeltaE) - ...` / `SQWW_U = int(DeltaN) - ...` のように `int()` を付けてからビルドする
- scikit-learn を入れると NumPy 2 に上がり、NumPy 1 向けにビルドした cshogi が読み込めなくなる → `pip install --no-build-isolation --force-reinstall --no-deps .` で cshogi をビルドし直す
- やねうら王（NNUE）は `engines/yaneuraou-std/`、評価関数は水匠5（`FV_SCALE 24`）。git 管理外

## 5. 実験で分かった、方法上の注意
- 評価関数を学習するとき、**教師が「強いAI同士の対局」だけだと駒の価値を学べない**（駒の損得がまれなため、飛車1枚の価値がほぼゼロに学習された）。深く読むと探索がその穴を突く（X11・X13）
- 「1手読み＋静止探索で NNUE の最善手と一致するか」は、静的な評価関数の質の物差しにならない（X7b）
- 証明つきの局所パターン（詰み・形）は、どうぶつしょうぎでも 9×9 でも流用できなかった（X4・X6・X12②）。大駒の長い利きと打ち駒のため、関連する範囲が盤の半分前後になる
- 実験の不具合は、結果が「深く読むほど悪くなる」など直感に反するときに見つかった（X2 の葉の即勝ちの扱い）。おかしいと思ったら疑う
