## 選び方（ユーザー指定の条件）
1. 撤退基準がはっきりしていて、何か月も検証を回し続けない
2. LLM のトークン消費が少ない（計算は裏で回し、自分は結果を読むだけ）
3. 失敗しても、他の案に使えるデータが残る
4. 複数の目標（①強さ ②軽さ ③証明）に効く
5. 中盤に新しい理論を持ち込める余地を少しでも残す
6. 9×9は「強いAI同士の新しめの棋譜で、定跡が長いもの」から始めて広げる

先行研究の調査を受けた変更: λ探索（B4/B5）と ZDD による後退解析（D1'）は既存なので、新規性の柱から外した。どうぶつしょうぎの解析は「正解データを作る基盤」と位置づける。

### X1 の結果の読み方（次に何をするかの判断表）
| 結果 | 解釈 | 次の一手 |
|---|---|---|
| KPP（線形）が小NNとほぼ同じ精度 | 小さい盤なら、3駒関係の線形で十分表現できる | 9×9で A5（KPP の低ランク化）を試す価値が上がる |

- 局面数（左右反転と手番を正規化、即勝ちの局面は終局として展開しない）: **213,993,386**
  - 手番側の勝ち 174,089,910（このうち即勝ちが 127,162,333）/ 負け 37,228,827 / 引き分け（千日手） 2,674,649
  - 勝敗が決まるまでの最長: **173手**

- 失敗から分かったこと（設計メモ）

### X1 評価関数の形ごとの表現力（2026-10-20 完了）
条件: 真値DBから無作為に300万局面（即勝ちを除くと約120万）で学習し、別の30万局面で評価。線形モデルは SGD のロジスティック回帰。GBDT と MLP はメモリの都合で30万局面だけで学習（それでも最良）。
「1手読みの誤り率」= 勝ち局面（どの手でもよいわけではないもの、63,142局面）で、評価関数が選んだ手が勝ちを逃す割合。相手に即勝ちを許す手は1手読みで分かるので、最初から除いている。

| 形 | 勝敗の当たり率 | 勝ち局面での1手読み誤り率 | 引き分け局面で負けに落ちる率 |
|---|---|---|---|
| ランダムに手を選ぶ | ― | 63.0% | 83.4% |
| 駒数だけ | 82.6% | 13.9% | 31.2% |
| 駒×位置（P） | 85.8% | 10.5% | 28.9% |
| 2駒関係（PP） | 87.2% | 7.1% | 24.3% |
| 3駒関係（KPP、Bonanza型） | 88.6% | **6.0%** | 23.3% |
| 任意3駒（PPP、ハッシュ） | 89.6% | 5.6% | 23.1% |
| 決定木（GBDT、非線形・非NN） | 90.5% | 5.3% | 20.6% |
| 小NN（MLP 256-32、参考） | 91.8% | **4.5%** | 18.2% |

**読み取れること**
1. 駒数だけ → KPP で、駒数だけと小NNの誤り率の差の**約84%**が埋まる。線形の3駒関係はかなり強い（Bonanza系が強かったことの小さい盤での裏づけ）
2. KPP → 任意3駒（PPP）では、ほとんど改善しない（6.0→5.6%）。**残りの差は「3駒の組み合わせを増やす」ことでは埋まらない**。非線形（決定木・NN）でしか縮まらない
3. それでも**小NNでも1手読みで4.5%間違え、引き分け局面では18%で負けに落ちる**。駒の配置から静的に評価するやり方自体に限界があり、残りは読みか、別の種類の知識（勝ちを保証する形・脅威の構造）が必要
4. 判断表では3行目に近い（「決定木・小NNにしか届かない」）。ただし KPP との差は小さい（誤り率 1.5pt）

### X1b 誤り分析（2026-10-20 完了）
詳細な表: `lab/results/x1b_errors.md`。両方（KPP と小NN）が間違えた 1,666 局面は `lab/data/dobutsu/hard.jsonl`。

| 局面の性質 | KPP誤り | 小NN誤り |
|---|---|---|
| 全体 | 6.5% | 4.5% |
| 勝ちまで 5手以内 | 約2.5% | 約1.6% |
| 勝ちまで 26〜45手 | 21.1% | 15.8% |
| 勝ちまで 46手以上 | 約25% | 約21% |
| 勝つ手が駒を取らない手だけ | 15.8% | 12.9% |
| 勝つ手に駒を取る手がある | 4.4% | 2.6% |
| 駒損（-2）なのに勝ち | 10.4% | 7.8% |
| 駒得（+3）で勝ち | 1.7% | 0.9% |
| 相手ライオンが前に出ている（1段目） | 9.7% | 5.9% |

**読み取れること**: 評価関数の誤りは**戦術ではなく、長期の勝ち筋（静かな手・駒損の代償・相手ライオンの前進）**に集中している。人間でいう「中盤の大局観」にあたる部分で、NNもここが弱い。KPP と小NNの差が大きいのは「相手ライオンが前に出ている」局面（トライの脅威の評価）。

### X4 証明済みパターン辞書（2026-10-20 完了）→ どうぶつしょうぎでは打ち切り
表: `lab/results/x4_patterns.md`、パターン: `lab/data/dobutsu/patterns.jsonl`（17,048件）
- 作り方: 勝つ手の行き先（相手の負け局面）から、DB全体を調べて「外しても全部負けのまま」のマスと持ち駒を貪欲に外していく（囲碁の Relevance Zone の考え方を、打ち駒のあるゲームに適用）
- **辞書の誤り 0 件**（証明済みなので当然。確認できた）
- 評価局面のうち辞書に当てはまった率 7.3%（撤退基準の1%は超えた）。ただし中身は 5手以内 14.1% / 26〜45手 1.0% / 46手以上 0.5〜1.0%
- **KPP の誤りを救えたのは 3,700 件中 53 件だけ**（誤り率 5.9% → 5.8%）。辞書が当たるのは、もともと KPP が正しく指せている短手数の局面
- パターンの大きさは、手数によらず 12マス中 約7.4マスを固定（両ライオンを含む）。長手数ほど当てはまる局面数の中央値が 1（＝その局面専用）になる

**結論**: 3×4 の小さい盤では「長期の勝ちに局所的な理由はない」（盤のほぼ全体が関係する）。証明済みパターンが効くのは戦術の範囲だけ。局所性が成り立つのは 9×9 の詰み・必至のまわりのはずなので、そちらに回す（候補 X6: 9×9 の詰み局面で、証明駒＋盤上の関連領域を一般化する）。
**副産物**: 「どの手数の勝ちが、どれだけ局所的か」を数値で測る方法ができた（9×9 でも同じ物差しが使える）。

### X5 脅威の構造の特徴量（2026-10-20 完了）
足した特徴量は13種類（`lab/dobutsu/x5_threats.py`）: ライオンの安全なマス数、トライの段までの距離とそこに安全に入れるマス数、相手ライオンの周りへの利きの数、浮き駒、自由度、王手。各特徴を「両ライオンの段」と掛け合わせた版も入れた。

| 評価関数 | 勝ち局面での1手読み誤り率 | 引き分け局面で負けに落ちる率 |
|---|---|---|
| KPP（X1） | 6.0% | 23.3% |
| 脅威の特徴量だけ | 14.7% | 37.5% |
| **KPP＋脅威（線形のまま）** | **5.3%** | 20.2% |
| 決定木（X1） | 5.3% | 20.6% |
| 決定木＋脅威 | 4.6% | 19.8% |
| 小NN（X1） | 4.5% | 18.2% |
| 小NN＋脅威 | 4.6% | 19.5% |

**読み取れること**
1. 13個の数値を足すだけで、線形のまま KPP→小NN の差の**約半分**が埋まり、決定木と同じ水準になる
2. 決定木に足すと小NNと同じ水準（4.6%）まで届く。**小NNに足しても改善しない** → NNが自力で学んでいたのは主に「脅威の構造」だった、という解釈と合う
3. 残る差（線形 5.3% と 非線形 4.6%）は、脅威の特徴量どうしの組み合わせ（「圧力が強く、かつ逃げ場が少ない」など）
4. 中盤理論への示唆: **「駒の配置」より「利きから生まれる脅威の数」で局面を記述するほうが、少ない部品で真値に近い**。9×9でも、玉の安全度・詰めろの数・浮き駒のような少数の脅威量が、3駒関係を補う候補になる

### X2 知識と読みの交換比（2026-10-20 完了）
条件: 勝ち局面（どの手でもよいわけではないもの）5,000件。全幅の negamax で、葉は評価関数の勝率。即勝ち（ライオンを取れる/トライ成立）はルールだけで分かるので確定値 1 とした。
（最初の実行は、葉の即勝ちを確定値にしていなかったため、深く読むほど悪化する誤った結果になった。`lab/data/x2_search_buggy.jsonl` に退避）

| 評価関数 | 1手読み | 2手読み | 3手読み | 3手読み・46手以上の勝ち |
|---|---|---|---|---|
| 駒数だけ | 13.8% | 7.1% | 5.7% | 26.2% |
| KPP | 6.1% | 4.1% | 2.8% | 21.4% |
| KPP＋脅威 | 5.5% | 3.6% | **2.3%** | 20.4% |
| 小NN | 4.5% | 2.8% | **1.8%** | 9.7% |

**読み取れること**
1. **交換比**: 「駒数だけ＋2手多く読む」≒「KPP で1手読み」。「KPP＋脅威＋1手多く読む」は「小NN」より誤りが少ない（2手 3.6% < 1手 4.5%、3手 2.3% < 2手 2.8%）。**非NNと小NNの差は、ほぼ1手分の読みに相当する**
2. 1手深く読むごとに、誤りはおよそ 0.6〜0.75倍になる
3. ただし**長期の勝ち（46手以上）は、線形の評価だと3手読んでも 20% 前後のまま**。小NNだけが 9.7% まで下がる → 長期の勝ち筋の知識は、浅い読みでは代わりにならない。ここが中盤理論の本丸
4. 目標②（スマホ）への示唆: 非NNの評価関数でも、読みを1手分深くできれば NN に並べる。線形評価は NN より計算が速いので、同じ時間で1手以上深く読めるなら、非NNが実戦で勝ちうる

### X7 9×9での評価関数の形ごとの表現力（2026-10-20 完了）
データ: floodgate 2026 の強豪AI同士 15,168局（対局単位で 9:1 に分割）。3手に1局面、学習 548,391 / 評価 61,811 局面。
教師: **棋譜に残るエンジン自身の評価値**（全手の74%に付いている。先手から見た値なので手番側に直し、tanh(評価値/1200) を回帰）。
（最初は対局の勝敗を教師にしたが、雑音が大きすぎて KP 系が過学習した → `lab/results/x7_expressivity_result_teacher.jsonl`）
9×9の脅威の特徴量（17種）: 自分と相手の指し手の数、王手、1手詰、詰めろ（相手から見た1手詰）、玉の逃げ道、玉の周りへの利き、取れる駒の数、玉の周りの金銀、玉の段、持ち駒の数。それぞれ序盤〜終盤の4段階と掛け合わせた版もある。

| 形 | 次元数 | 評価値との相関 | NNUE最善手との一致（1手読み） |
|---|---|---|---|
| ランダム | ― | ― | 2.1% |
| 駒数だけ | 42 | 0.493 | **12.1%** |
| 駒×位置（P） | 約2,500 | 0.547 | 9.7% |
| 玉×駒×位置（KP、NNUEの入力層を線形で） | 約45万 | 0.576 | 7.0% |
| 脅威だけ（T） | 約1,400 | 0.407 | 5.0% |
| KP＋脅威 | 約45万 | 0.599 | 7.5% |
| 決定木（駒数＋脅威の約60個の数値だけ） | 59 | **0.608** | 6.1% |

**読み取れること**
1. 9×9でも、**脅威の特徴量で KP が伸びる**（0.576→0.599）。どうぶつしょうぎ（X5）と同じ傾向
2. **決定木が、約60個の数値（駒数＋脅威）だけで、45万次元の KP＋脅威と同等以上**。少数の脅威量が評価の大部分を担っている。目標②（スマホ向けの小さい評価関数）と中盤理論の両方にとって有望な手がかり
3. NNUE 最善手との一致は、駒数だけが最良という逆転が起きた。1手読みの静的評価では、取り返される駒取り（駒の取り合い）を正しく評価できないため。**指し手の質を測るには静止探索（駒の取り合いだけを読む）が必要** → X7b
4. 相関の絶対値は 0.6 前後と低め。教師はエンジンごとに評価値の目盛りが違い、強豪AI同士の局面は互角に近いものが多いので、雑音が大きい

### X7b 静止探索つきで NNUE の最善手と一致するか（2026-10-20 完了）→ 指標として打ち切り
各候補手の後で駒を取る手（王手なら全ての応手）だけを深さ4まで読み、NNUE の最善手と一致する率を、最善手が駒を取る手かどうかで分けて集計（2,000局面。NNUE の最善手のうち駒を取る手は 23%）。

| 評価関数 | 全体 | 最善手が駒を取る手 | 最善手が駒を取らない手 |
|---|---|---|---|
| 駒数だけ | **19.5%** | **58.2%** | **8.6%** |
| 駒数＋駒×位置 | 14.2% | 37.0% | 7.8% |
| 駒数＋KP | 12.1% | 34.0% | 5.9% |
| 駒数＋KP＋脅威 | 12.7% | 34.7% | 6.5% |
| 駒数＋脅威 | 13.5% | 32.7% | 8.1% |
（同点のとき合法手の先頭を選ぶ偏りは小さい: 常に先頭の手を選ぶと 2.9%）

**結論**: 学習した評価関数は、駒を取らない手では「安全な手の中から無作為に選ぶ」のと変わらない。駒の取り合いでは駒の価値の学習が崩れて、駒数だけに負ける。駒を取らない手で強いAIの選択を再現するには深い読みが必要で、**この指標では静的評価の質を測れない**。9×9の評価関数の比較は X7 の相関で行い、指し手の質は対局で測る（エンジン化が必要）。

### X8 脅威の構造から人が読める規則を取り出す（2026-10-20 完了）
詳細と木の全文: `lab/results/x8_rules.md`。入力は脅威の特徴量13種＋駒の枚数の差（14個の数値）だけ。

| 規則の数（決定木の葉） | 1手読み誤り率 |
|---|---|
| 8 | 13.8% |
| 16 | 12.4% |
| 60 | 11.1% |
| 167 | 10.5% |
| 勾配ブースティング（14個の数値の非線形） | 8.3% |
| 比較: 駒数だけ / KPP / KPP＋脅威 | 13.9% / 6.0% / 5.3% |

- 重要度の順: 駒の枚数の差 ≫ 相手の浮き駒 ≒ 相手ライオンの自陣奥までの距離 ≒ 自分の自由度 > 玉の周りへの利き（両方向）
- 読める規則の例: **「駒を2枚以上得していても、相手ライオンが自陣奥まで1段以内に来ていて、奥の段に安全に入れるマスがあれば負け」**（トライの脅威が駒得に優先する）
- **結論**: 脅威の量だけでは、駒の配置の知識（KPP）を置き換えられない（8.3% vs 6.0%）。両者は補い合う関係で、組み合わせたとき（X5、5.3%）が最良。人が読める規則は、駒得の判断に脅威による例外を足す形になるが、本数を増やしても精度の伸びは緩やか

### X9 長期の勝ちの手順の中身（2026-10-20 完了）
真値DBで最善手順（勝つ側は最短、負ける側は最長で粘る）を終局までたどり、勝つまでの手数の区分ごとに 1,500件ずつ集計。表: `lab/results/x9_long_wins.md`

| 指標 | 15手以内 | 16〜45手 | 46〜80手 | 81手以上 |
|---|---|---|---|---|
| 開始時に駒損している率 | 13% | 32% | 43% | **59%** |
| 駒の枚数の差（開始 → 中間 → 終局直前） | +1.2 → +2.3 → +2.2 | −0.3 → +1.3 → +2.4 | −0.7 → +0.5 → +2.5 | **−1.3 → +0.1 → +2.5** |
| 10手あたりのライオンの手（勝つ側 / 負ける側） | 0.9 / 1.7 | 1.5 / 1.9 | 1.7 / 1.7 | **1.9 / 1.2** |
| 10手あたりの打ち駒（勝つ側） | 0.7 | 1.3 | 1.3 | 1.3 |
| トライで終わる率（ライオンの位置からの簡易判定） | 26% | 29% | 23% | 6% |

**読み取れること（中盤理論の仮説）**: 長期の勝ちは「**駒損から始まり、ライオンを攻めに使い、持ち駒を打って圧力をかけ、時間をかけて駒を取り返す**」型。負ける側のライオンは動けなくなっていく。評価関数が駒損の局面の勝ちを見落とす（X1b）のは、この「ライオンの活動力」という代償を評価できていないからではないか
→ 検証: ライオンの活動力（前方へ安全に動けるマス数・中央にいるか）と「駒の枚数の差 × ライオンの段」を X5 の特徴量に足す（X9b）

### X10 どうぶつしょうぎの中盤理論 — 人が読める規則と全数検証（2026-10-20 完了）
表の全文: `lab/results/x10_theory.md`。人が読める条件（駒の枚数の差・ライオンの段・前方へ安全に動けるマス・浮き駒・玉の周りへの利きなど16種）を最大3つ AND でつないだ規則をビームサーチで探し、別の局面で確認し、最後に真値DBの全局面（即勝ちを除く）で例外を数えた。

**定理（到達可能な全局面で例外なし）**
1. **「相手ライオンが自陣側の半分（段 ≥ 2）にいて、前方へ安全に動けるマスが2つ以上あれば、手番側の負け」**（62,926局面、例外 0）＝ 二方向のトライの脅威は受からない
2. 「駒の枚数で6枚負けていて、自ライオンに安全な逃げ場がなければ負け」（716,637局面、例外 0。ほぼ自明）

**ほぼ定理（例外が 0.01% 未満）**
- 「駒を5枚以上得していて、相手ライオンが相手陣側（段 ≤ 1）にいれば勝ち」（491,334局面、例外 44）
- 「駒を3枚以上得していて、自ライオンの周りに相手の利きがなければ勝ち」（940,598局面、例外 879 = 99.91%）

**駒得なのに負ける規則（トライの脅威）**
- 「王手されていて、相手ライオンが自陣側にいて、自陣の奥に安全に入れるマスがあれば、駒得していても 85% は負け」（125,831局面）
- 「駒得 2枚以下で、相手ライオンが自陣側にいて前に進めるなら 72% は負け」（543,123局面）

**駒損なのに勝つ規則は弱い**: 最良でも 57%（もともとの割合 21%）で、中身は「相手の浮き駒が2つ以上」という戦術。**X9 の「ライオンの活動力で駒損を補う」は、条件3つまでの規則としては表せなかった**。決定木（非線形）では効いた（X9b）ので、補い方は条件の組み合わせが多く、短い規則には収まらない

**結論**: 「トライの脅威」は人が読める短い規則（定理を含む）に落とせた。一方、「長期の逆転」は短い規則に収まらない。中盤理論として書けるのは「危険の規則」（こうなったら負け）で、「逆転の規則」は評価関数（非線形の非NN）として持つほうがよい

### X6 9×9 の詰みの関連領域（証明つき）と流用率（2026-10-20 完了）→ 打ち切り
表: `lab/results/x6_mate_zones.md`（厳密版）/ `x6_mate_zones_cons.md`（精密版）。部品: `lab/nine/zone.py`（読み取りを記録する将棋の規則。実戦の王手 23,061局面で cshogi の合法手と完全一致）
- 作り方: 強豪AI同士の終盤から 9手以内の詰み（王手の連続）がある局面を集め（学習側 13,652局 → 11,201件）、詰ませる手は cshogi から受け取り、証明木の全ノードで王手と受けの全列挙を「読んだマスを記録しながら」確かめる。読んだマス＝関連領域（他のマスに何があっても同じ手順で詰む）
  - 厳密版: 読んだマスの中身を固定
  - 精密版: マスごとに「許される駒の集合」を記録（遠くの大駒の利きを否定するために読んだ空きマスは「利く駒以外なら何でもよい」）
- 関連領域の大きさ（81マス中、平均）: 1手詰 37.7 / 3手 45.3 / 5手 51.2 / 7手 56.2 / 9手 60.1。精密版で中身まで固定するのは 9.1 / 13.2 / 17.4 / 21.7 / 25.8
- **評価側（1,516局、20.9万局面）の詰み局面 1,376件のうち、パターンで見つかったのは 厳密版 0件 / 精密版 2件（0.1%）**。当てはまった局面が詰まなかった例は 0件
- パターン照合 31µs / 局面（Python）、cshogi の詰み探索 270µs / 局面（C++）

**結論**: 将棋では、詰みを「他は何でもよい」形で証明するのに、大駒の長い利きと打ち駒のせいで盤の半分前後を読む必要がある。中身を固定するマスに絞っても 9〜26マス残り、実戦で同じ形はほぼ再び現れない。**どうぶつしょうぎ（X4）と同じく、証明つきの局所パターンは流用できない**。流用を狙うなら、平行移動（玉を基準にした相対位置）を許す一般化が必要だが、段によって成りや行き所のない駒の規則が変わるので、証明の正しさを保てるのは横方向の移動だけ。

## フェーズ0のまとめ（2026-10-20）
1. **小さい盤（どうぶつしょうぎ）での真値と評価関数の距離**: 駒数 13.9% → 駒×位置 10.5% → 2駒 7.1% → KPP 6.0% → KPP＋脅威 5.3% → 小NN 4.5%（1手読みの誤り率）
2. **誤りは長期の勝ち筋に集中**（静かな手・駒損の代償・相手ライオンの前進）。証明済みの局所パターンは戦術にしか効かず、長期の勝ちは盤全体が関係する（X4）
3. **知識と読みの交換比**: 非NN（KPP＋脅威）と小NNの差は約1手分の読み。ただし長期の勝ちは浅い読みでは補えない（X2）
4. **9×9でも「脅威の量」が KP を補う**。少数の数値（約60個）の決定木が、45万次元の線形 KP に並ぶ（X7）
5. 静的評価の質を「1手＋静止探索での最善手一致」で測るのは無理。指し手の質は対局で測る必要がある（X7b）

**次のフェーズの候補**
- A（目標②の直接検証）: どうぶつしょうぎで、KPP＋脅威の線形評価と小NN評価をそれぞれ C の αβ探索に載せ、**同じ時間（＝線形は深く読める）で対局させる**。真値DBで両者の手の正しさも測れる。「速さで知識を補えるか」を最も直接に確かめられる
- B（中盤理論）: 長期の勝ち（46手以上）の局面だけを集め、何が勝ちを決めているかを差分で調べる（勝ち局面と、1手違いの負け局面の対比）
- C（目標③・9×9）: 9×9の詰み・必至まわりで、証明駒＋盤上の関連領域の一般化（X6）。局所性が成り立つのはここ

**次の一手（判断）**
- X1b（誤り分析）: KPP も小NNも間違える「難所」の局面を集め、終局までの手数・トライの脅威・持ち駒・静かな手（駒を取らない手）が正解かどうかで分類する。中盤理論の材料になり、X4 でどのパターンを狙うかも決まる。トークンをほとんど使わない集計だけで済む
- X4（証明済みの局所パターン）: 難所を説明できる「勝ちを保証する形」を真値DBから抜き出し、KPP に特徴量として足したときに小NNを超えられるか → 超えれば「非NNでNN以上」の小さい実証になる
